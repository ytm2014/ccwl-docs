## The APIs

| | Messaging API | Publishing API | Link in Bio API |
| --- | --- | --- | --- |
| Covers | Contacts, tags, segments, conversations, messages, broadcasts, automations, media | Social accounts, posts, scheduling, approval, tags, media | Bio pages and blocks, short links, QR codes, pixels, form submissions, analytics, custom domains |
| Base URL | `https://app.example.com/api/v1` | `https://app.example.com/os/api/{workspace-uuid}` | `https://app.example.com/api/v1/biolinks` |
| Workspace | Chosen by the API key | In the URL, and must match the API key | Chosen by the API key |

One workspace API key can call every API, as long as you give it the permissions for each when you create it.

<Note>
Some features depend on your plan and on what your platform has turned on. If an endpoint returns `404` even with a valid key, the feature is not available on your workspace yet.
</Note>

Bluesky posts are short and can be chained into threads. The Bluesky options add hidden tags that help people find the post, and a moderation label for sensitive content.

## Limits

| Item | Limit |
| --- | --- |
| Text | 300 characters, counted the way Bluesky counts them. |
| Media | Up to 4 photos, or 1 video, or 1 GIF. Media types can't be mixed. |
| Content | Text or media is required. |
| Extra items | Thread (**Add Post**). |

## Bluesky options

| Setting | What it does |
| --- | --- |
| **Hidden tags** | "Tags improve searchability but remain hidden. Up to 8 tags allowed. Press Enter to separate them." |
| **Content Moderation Label** | Labels sensitive content so Bluesky can warn or hide it. Leave it empty for no label. |

The moderation labels are:

| Label | Use it when |
| --- | --- |
| Adult Content (+18) | The post contains pornographic content for adults only. |
| Sexual Content | The post contains sexually explicit content. |
| Nudity | The post contains nude images or videos. |
| Graphic Media | The post contains graphic or gory content. |
| No Authentication required | The post should be visible to people who aren't logged in. |
| Automated Bot | The post comes from an automated bot. |

## Write a thread

Click **Add Post** under the editor to add the next post of the thread. If you paste text longer than 300 characters, the composer offers **Split into ... posts**. See [Threads and first comments](/guide/publishing/threads-and-first-comments).

## Tips

- 300 characters goes quickly. Give the Bluesky account its own [version](/guide/publishing/post-versions) with a shorter text, or use a thread.
- Link cards appear for links in your text; the **Preview** tab shows an approximation.

## Troubleshooting

| Message | What to do |
| --- | --- |
| **Maximum of 300 characters allowed.** | Shorten the text or split it into a thread. |
| **Maximum of 4 photos allowed.** | Remove photos or spread them over the thread. |
| The account shows as disconnected | Reconnect it on the **Accounts** page. |

Each Pinterest post becomes a Pin on a board. You choose the board for every Pinterest account in the post, and can give the Pin a title and a link.

## Limits

| Item | Limit |
| --- | --- |
| Text (Pin description) | 500 characters. |
| Media | Required: 1 photo or 1 video. |
| Video length | 4 seconds to 5 minutes. |
| Board | Required for each Pinterest account. |
| Extra items | None. |
| Video cover | A thumbnail image can be set. See [Add media to a post](/guide/publishing/add-media#video-covers). |

## Pinterest options

| Setting | What it does |
| --- | --- |
| **Title** | The Pin's title. |
| **Link** | The page the Pin opens. It must be a full address starting with https://. |
| **Select a board for ...** | One board list per Pinterest account. Required. |

## Create a board

If the board you need doesn't exist yet:

1. Next to the account's board list, click **Create Pinterest Board**.
2. Enter the **Board name**.
3. Click **Create Pinterest Board**. The board is created on Pinterest and can be chosen right away.

## Tips

- Put the link in the **Link** field, not only in the description, so the Pin opens your page.
- With several Pinterest accounts, check that each one has a board before scheduling.

## Troubleshooting

| Message | What to do |
| --- | --- |
| **Choose a board.** | Pick a board for every Pinterest account. |
| **Enter a valid link, starting with https://.** | Fix the **Link**. |
| **Add a photo or a video.** | Pins need media. |
| "The board could not be added" | Try again, or create the board on Pinterest and reload. |
| "Error uploading the video. Try again later or try another video." | Pinterest refused the video. Try again or use another file. |

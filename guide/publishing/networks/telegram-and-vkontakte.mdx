You can schedule posts to Telegram channels and to VKontakte like any other network. Neither has extra options in the composer: write the text, add media and schedule.

## Telegram

Posting goes to a Telegram channel connected as **Telegram channel (posting)** on the **Accounts** page. This is separate from a Telegram bot used for messaging in the inbox.

| Item | Limit |
| --- | --- |
| Text | 4,500 characters. |
| Media | Up to 10 photos, or 1 video, or 1 GIF. Media types can't be mixed. |
| Content | Text or media is required. |
| Extra items | None. |
| Video cover | A thumbnail image can be set. See [Add media to a post](/guide/publishing/add-media#video-covers). |

## VKontakte

| Item | Limit |
| --- | --- |
| Text | 1,000 characters. |
| Media | Up to 1 photo, or 1 video, or 1 GIF. |
| Content | Text or media is required. |
| Extra items | None. |

## Tips

- Both networks publish a single post. If you select them together with a thread network, only the first post of the thread goes out on Telegram or VKontakte.
- Check the **Preview** tab for an approximation of the post.

## Troubleshooting

| Message | What to do |
| --- | --- |
| **Maximum of ... characters allowed.** | Shorten the text, or give the account its own [version](/guide/publishing/post-versions). |
| **Combining different media types (videos, photos, GIFs) is not allowed.** | Use one media type. |
| Publishing failed | Check the reason on the **Delivery** tab, and that the account is still connected. See [Failed posts](/guide/publishing/failed-posts). |

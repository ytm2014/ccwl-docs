Google Business Profile posts appear on your business listing in Google Search and Maps. A post can be a standard update, an offer or an event.

## Limits

| Item | Limit |
| --- | --- |
| Text | 1,500 characters. |
| Media | Up to 1 photo. |
| Extra items | None. |

## Post types

Choose the type in **Google Business Profile options**:

### Post

A standard update. Optionally add a call-to-action **Button**:

| Button | Needs a **Button link** |
| --- | --- |
| **None** | No |
| **Book**, **Order online**, **Buy**, **Learn more**, **Sign Up** | Yes |
| **Call now** | No |

### Offer

| Field | Notes |
| --- | --- |
| Title | Required. |
| **Start Date** and **End Date** | Required. The end date can't be before the start date. |
| **Add more details** | Switch on to add a **Coupon Code**, an **Offer Link** (a full https:// address) and **Terms & Conditions**. |

### Event

| Field | Notes |
| --- | --- |
| **Event Title** | Required. |
| **Start Date** and **End Date** | Required. Switch on **Add time** to add a **Start Time** and **End Time**. |
| **Button** and **Button link** | Optional call to action, as for a post. |

If dates are missing, the options warn: "Choose a start date and an end date, or Google will reject this post."

## Media category

When the post has a photo, a second box offers **Media Category** (for example cover, logo, exterior, interior, product, food and drink, menu or team). It is used when the post has media and no text: the photo goes to your profile's photos in that category.

## In RSS campaigns

In an [RSS campaign](/guide/publishing/rss-campaigns), an event or offer without start and end dates is posted as a standard update.

## Troubleshooting

| Message | What to do |
| --- | --- |
| **Add a title.** | Offers and events need a title. |
| **Choose a start and an end date.** | Set both dates. |
| **The end date is before the start date.** | Fix the dates. |
| **Add a link for the button.** | Enter the **Button link**, or choose **None** or **Call now**. |
| **Enter a valid link, starting with https://.** | Fix the button or offer link. |

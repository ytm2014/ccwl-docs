Threads posts can carry text, photos and videos, and can be chained into a thread of replies. You can also publish several media items as a carousel and add a location.

## Limits

| Item | Limit |
| --- | --- |
| Text | Shown by the composer's counter for Threads. |
| Media | Up to 20 items; photos and videos can be mixed. |
| Video length | Up to 5 minutes. |
| Content | Text or media is required. |
| Extra items | Thread (**Add Post**). |

## Threads options

**Threads options** has one setting:

- **Publish the media as a carousel**: publishes the post's media as one swipeable carousel. "A carousel needs at least two media items."

## Write a thread

Click **Add Post** under the editor to add a reply to the thread. You can split, merge, reorder and number the posts. See [Threads and first comments](/guide/publishing/threads-and-first-comments).

## Add a location

<Steps>
  <Step title="Save the post">
    The location needs a saved post: "Save the post first, then add a location."
  </Step>
  <Step title="Open Add Location">
    Click the location pin in the editor toolbar (**Add Location**).
  </Step>
  <Step title="Search">
    Type the place under **Type to search** and pick it from the list. The button's tooltip then shows the chosen location.
  </Step>
</Steps>

The location is only used by Threads; other networks ignore it. Threads must be on auto publish mode for the location to be used. If nothing matches, the dialog says **No locations found**.

## Tips

- Threads shows link previews for links in your text. The **Preview** tab shows an approximation.
- Mention other profiles with saved [mentions](/guide/publishing/mentions).

## Analytics

Threads accounts have reports in **Analytics**: overview, engagement, content, hashtags and insights. See [Account analytics](/guide/publishing/account-analytics).

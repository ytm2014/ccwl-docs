Tumblr has several post types, each displayed differently on your blog. You choose the type in the Tumblr options, and some types add a field of their own.

## Limits

| Item | Limit |
| --- | --- |
| Text | 1,000 characters. |
| Media | Up to 1 photo, or 1 video, or 1 GIF. |
| Extra items | None. |

## Tumblr options

Choose the **Post type**:

| Post type | Extra field | Notes |
| --- | --- | --- |
| **Text post** | **Post title (optional)** | The post text is the body. |
| **Photo post** | None | Add a photo to the post. |
| **Quote post** | None | "Note: all HTML character entities must be escaped (\\)." |
| **Link post** | **Link** (required) | "A link post needs a link." |
| **Chat post** | **Chat title (optional)** | Write the chat lines in the post text. |
| **Video post** | None | Add a video to the post. |

## Tips

- Match the media to the type: a **Photo post** needs a photo, a **Video post** a video.
- Use a separate [version](/guide/publishing/post-versions) for Tumblr if the text should differ from your other networks.

## Troubleshooting

| Message | What to do |
| --- | --- |
| **A link post needs a link.** | Enter the **Link**, or choose another post type. |
| **Maximum of 1,000 characters allowed.** | Shorten the text. |

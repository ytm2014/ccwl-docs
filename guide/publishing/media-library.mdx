The **Media Library** keeps the images and videos you use in posts. Upload files once, sort them into folders and pick them from the composer whenever you need them. The same library opens when you click **Add Media** in the composer.

In the sidebar, open **Media Library**. Every member can browse it; uploading, organising and deleting need the **Admin** or **Member** role.

## Upload files

On the **Upload** tab:

- Drag files or whole folders onto the page, or click **Browse**. Images and videos only.
- **Upload folder** uploads a folder and keeps its structure. Folders nested too deep are flattened into the deepest level allowed.
- **From URL**: paste an image or video link to upload it.
- **AI**: describe an image (**Describe the image**) and click **Generate** to create one. It can take a couple of minutes. Shown only when AI images are available.

Files go into the folder you have open. An upload panel shows the progress of each file (**Waiting...**, **Uploading**, **Complete** or **Failed**). Unsupported formats show a message listing the formats you can use.

Where your plan has a storage limit, the library shows how much you have used, for example "2 GB of 10 GB used". **Get Storage** lets you add more where available.

## Folders

Open the folder panel with the folder button beside the tabs.

- Click **New folder** to create one, inside the open folder if you are in one. Folders can be nested a few levels deep.
- Open a folder's menu to **Rename folder**, add a folder inside it, move it, or delete it. **Delete folder** moves its files to the parent folder; **Delete folder and files** deletes the files too.
- Use **Search folders** to find a folder.
- Drop files on the page while a folder is open to upload them into it.

The panel also has **Recents** and **Favourites**. Star a file (**Add to favourites**) to find it in **Favourites** later.

## Find files

- **Search by name** searches the whole library.
- **Filters** narrows by **Type** (**Images**, **GIFs** or **Videos**) and **Usage**: **Published**, **Scheduled**, **Draft** or **Not used** in posts. Each file shows a badge when it is used in posts.
- **Sort by**: **Newest first**, **Oldest first**, **Name (A-Z)** or **Largest first**.

## Work with a file

Hover over a file and open **More actions**:

| Action | What it does |
| --- | --- |
| **Preview** | Shows the file full size, or plays a video. |
| Rename | Changes the file's name. |
| **Edit alt text** | Describes the image for screen readers; may offer **Generate with AI**. |
| **Edit image** | Opens the image editor. Your edits are saved as a new copy ("Edited copy saved"). |
| **Create for Adobe Express** | Starts a design from the file, where available. |
| **Move to folder** / **Copy to folder** | Moves or copies it to another folder. |
| **Copy URL** | Copies the file's address. |
| Delete | Removes the file. |

## Work with several files

Click files to select them. The bar that appears lets you:

- **Create Post**: start a post with the selected files.
- **Move to folder** or **Copy to folder**.
- **Delete**, after you confirm ("Are you sure you want to delete selected media items?").

<Warning>
Deleting media removes it from the library. Check the usage badge first: a file used in scheduled posts may still be needed.
</Warning>

## Other sources

Besides your uploads, the library has tabs for stock photos, GIFs, Canva, Google Drive, Dropbox and new designs. See [Media sources](/guide/publishing/media-sources).

## Troubleshooting

| Message | What to do |
| --- | --- |
| **The {format} file is not supported.** | Convert it to a listed format. |
| **Error uploading media.** / **The media could not be uploaded. Try again.** | Try again; check the file size and your storage. |
| **A folder with this name already exists here.** | Choose another name. |
| **Folders can be nested up to ... levels deep.** | Create the folder higher up. |

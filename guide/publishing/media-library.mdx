The **Media Library** keeps the images and videos you use in posts. Upload files once, sort them into folders, and pick them from the composer whenever you need them. The same library opens when you click **Add Media** in the composer.

In the sidebar, open **Media Library**. Every member can browse it; uploading, organising and deleting need the **Admin** or **Member** role.

## Sources

The tabs across the top are where media can come from. Which ones you see depends on your plan and platform.

| Tab | What it does |
| --- | --- |
| **Upload** | Your own files, with folders. |
| **Stock Photos** | Search a stock photo service and use a photo. |
| **GIFs** | Search for GIFs. |
| **New design** | Create a design for Adobe Express. |
| **Canva** | Connect your Canva account and import your designs (**Import Design**), choosing format and quality. |
| **Google Drive** and **Dropbox** | Pick files from your cloud storage. Larger files download in the background and you are notified when they are ready. |

Media from stock, GIF and cloud sources is saved to your library when you use it.

## Upload files

On the **Upload** tab:

- Drag files or whole folders onto the page, or click **Browse**. Images and videos only.
- **Upload folder** uploads a folder and keeps its structure.
- **From URL**: paste an image or video link to upload it.
- **AI**: describe an image and click **Generate** to create one. Only shown when AI images are available.

Files go into the folder you have open. Unsupported formats show a message listing the formats you can use.

## Folders

Open the folder panel with the folder button beside the tabs.

- Click **New folder** to create one, inside the open folder if you are in one.
- Open a folder's **More actions** menu to **Rename folder**, add a **New folder** inside it, or delete it. **Delete folder** moves its files to the parent folder; **Delete folder and files** deletes the files too.
- Use **Search folders** to find a folder.

The panel also has **Recents** and **Favourites**. Star a file (**Add to favourites**) to find it in **Favourites** later.

## Find files

- **Search by name** searches the whole library.
- **Filters** narrows by **Type** (images, GIFs or videos) and **Usage**: **Published**, **Scheduled**, **Draft** or **Not used** in posts. Each file also shows a badge when it is used in posts.
- **Sort by**: **Newest first**, **Oldest first**, **Name (A-Z)** or **Largest first**.

## Work with a file

Hover over a file and open **More actions**:

- **Preview**: see the file full size, or play a video.
- **Rename**.
- **Edit alt text**: describe the image for screen readers. The dialog says which networks use it, and may offer **Generate with AI**.
- **Edit image**: open the image editor. Your edits are saved as a new copy.
- **Create for Adobe Express**: start a design from the file.
- **Move to folder** or **Copy to folder**.
- **Copy URL**: copy the file's address.
- **Delete**.

## Work with several files

Click files to select them. The bar that appears lets you:

- **New post**: start a post with the selected files.
- **Move to folder** or **Copy to folder** (on the **Upload** tab).
- **Delete**, after you confirm.

<Warning>
Deleting media removes it from the library. Check the usage badge first: a file used in scheduled posts may still be needed.
</Warning>

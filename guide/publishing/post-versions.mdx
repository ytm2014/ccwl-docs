When a post goes to several accounts, they all publish the **Original** version unless you give one of them its own. A version lets you shorten the text for X, add a different image for Instagram or change the options for one account, while the rest keep using the original.

## How versions work

As soon as you select more than one account, tabs appear above the editor:

- **Original** is the shared version. A small marker shows how many accounts use it.
- Each account with its own version gets a tab with the network's icon and the account name.
- A coloured dot on a tab means that version has a problem to fix. See [Preview and checks](/guide/publishing/preview-and-checks).

If every selected account has its own version, the original is not published anywhere, and the composer tells you so: "Every selected account has its own version, so the original is not published anywhere."

## Create a version

<Steps>
  <Step title="Open the version menu">
    Click **+** (**Create version**) next to the tabs. It appears when at least two accounts still use the original.
  </Step>
  <Step title="Pick the account">
    Under **Create version for**, choose the account. A new tab opens, starting from a copy of the original.
  </Step>
  <Step title="Edit it">
    Change the text, media and network options on that tab. Changes here affect only this account.
  </Step>
</Steps>

## Version actions

Open **Version actions** (the three dots next to the tabs) on the tab you are looking at:

| Action | What it does |
| --- | --- |
| **Copy from another version** | Copies the text, the media or both from another version (or the **Original**) into this one. |
| **Apply to other accounts** | Copies this version's text, media or both into other accounts. Each account shows **Customized** or **Uses the original**. |
| **Sync with** | Makes this version follow another one. See below. |
| **Stop syncing** | Ends the link to the version it followed. |
| **Make this the original** | Makes this version the shared one, so the accounts using the original get this content. |
| **Reset to original** | Removes this account's own version, so it uses the original again. |

When you copy or apply, choose under **What to copy** whether to take the **Text**, the **Media** or both, then click **Copy** or **Apply**. Applying replaces the chosen accounts' content; a message lets you undo it right away.

### When the content has more posts than a network allows

If the version you copy is a thread and the target network publishes fewer posts (for example a network that publishes a single post), **Too many posts** asks what to do:

- **Keep only the posts that fit**, or
- **Join the extra posts into the last one**.

A version that has already been trimmed shows a note that the rest were left out, with **Join them into the last post**.

## Keep versions in sync

A synced version shows the same text and media as its source and follows every change you make there. Its network options stay its own, so you can, for example, keep the same caption for two Instagram accounts while choosing **Reel** for one and **Post** for the other.

1. On the account's tab, open **Version actions**.
2. Under **Sync with**, pick the source (another account or **Original**).

The tab then shows "This version is synced with ...", with **Edit** to jump to the source and **Stop syncing** to make it independent again.

## Tips

- Create versions only where you need them. Every account without a version picks up changes to the original automatically.
- Some networks refuse the same text on several accounts. The **Suggestions** tab offers **Create separate versions** when that happens.
- Network options such as a YouTube title or a Pinterest board belong to each version. Check them on every tab before you schedule.

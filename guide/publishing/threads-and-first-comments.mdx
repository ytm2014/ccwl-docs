A post can hold more than one item. On networks that publish threads, extra items become replies in a thread. On networks that support it, a second item becomes the first comment under your post. The composer shows the right button for the accounts you selected.

## Which networks support what

| Content | Networks | Button |
| --- | --- | --- |
| Thread | X, Threads, Bluesky, Mastodon, Pixelfed | **Add Post** |
| First comment | Facebook Page, Instagram, YouTube, and LinkedIn where your platform supports it | **Add first comment** |
| Single post | TikTok, Pinterest, Google Business Profile, Reddit, Tumblr, Telegram, VKontakte | None |

Stories (Facebook, Instagram) never get a first comment, and YouTube only takes one when the video is not **Made for kids** and is not a livestream.

## Write a thread

<Steps>
  <Step title="Write the first post">
    Write the opening post as usual.
  </Step>
  <Step title="Add posts">
    Click **Add Post** under the editor. A new item appears, numbered along the thread rail. Repeat for each post.
  </Step>
  <Step title="Arrange them">
    Open an item's **Post actions** menu to **Split at cursor**, **Merge with previous**, **Duplicate**, **Move up**, **Move down** or **Delete** it. You can also drag items by their handle.
  </Step>
  <Step title="Number them (optional)">
    Switch on **Number the posts** to add numbering to each post of the thread.
  </Step>
</Steps>

Keyboard shortcuts are shown under the editor: one splits the post at the cursor, others move an item up or down.

### Split long text automatically

If you paste more text than a network publishes in one post, the composer offers to split it: "That is ... characters, more than ... publishes in one post." Click **Split into ... posts** to turn it into a thread.

### Mixed accounts

When a post goes to a thread network and a single-post network at once, only the first item is published on the single-post network. The composer warns you: "Only the first post is published on ...". Give that account its own [version](/guide/publishing/post-versions) if it needs different text.

## Add a first comment

<Steps>
  <Step title="Write the post">
    Write the post as usual.
  </Step>
  <Step title="Add the comment">
    Click **Add first comment**. A second item appears with a **First Comment** header.
  </Step>
  <Step title="Write the comment">
    Type the comment. It is published right after the post, as a comment from the same account.
  </Step>
</Steps>

A post has one first comment; anything beyond it is ignored ("The first comment is limited to one item, the rest will be ignored."). Accounts that can't take a first comment show "The first comment will not be published on ...".

### What a first comment can contain

| Network | Text | Media |
| --- | --- | --- |
| Facebook Page | Required | Up to 1 photo or GIF |
| LinkedIn | Required | Up to 1 photo or GIF |
| Instagram | Required | None |
| YouTube | Required, up to 10,000 characters | None |

<Tip>
Put links in the first comment on networks that show fewer people posts with links. The **Suggestions** tab offers **Move the link to the first comment**. See [Links in posts](/guide/publishing/links-in-posts).
</Tip>

## Retry a thread that stopped halfway

If a thread fails partway, the **Delivery** tab shows how many parts went out ("2 of 5 parts published"). **Continue publishing** resumes from the part that failed; the parts already published stay as they are. See [Failed posts](/guide/publishing/failed-posts).

## Troubleshooting

| Message | What to do |
| --- | --- |
| **The first comment needs text.** | Write something in the first comment, or delete it. |
| **The first comment cannot include photos or videos.** | Remove the media from the comment for this network. |
| **Post is required for First comment/Thread** | The first item is empty. Write the main post first. |

A saved mention holds one name and the handle that name has on each network. When you insert it into a post, every network gets its own handle: `@acme` on X, the linked company page on LinkedIn, and so on. Networks without a handle get the name as plain text, so the post still reads naturally.

## Insert a mention

You can insert a mention in two ways:

- **Type `@`** in the editor followed by a few letters. A list shows your saved mentions that match; pick one. If none matches, you can create one from what you typed.
- **Click the Mention Manager** button in the editor toolbar and click **Use** next to a mention.

In the text, a mention shows as a chip. Hover over it to see where it is linked ("Tagged on every selected network") and where it goes out as plain text ("Not tagged on ...: the name goes out as plain text. Click to add a handle.").

## Create a mention

<Steps>
  <Step title="Open the Mention Manager">
    Click the mentions button in the editor toolbar, then **New Mention**.
  </Step>
  <Step title="Enter the name">
    Under **Name**, type the name as it should read in the post, for example a person or company name.
  </Step>
  <Step title="Add a handle per network">
    Under **Networks**, add the handle for each network you use. For some networks you can search for the profile with **Search on** the network, so the mention is linked to the right page. Add one handle per network.
  </Step>
  <Step title="Save">
    Click **Save Mention**.
  </Step>
</Steps>

The mention is now available in every post in your workspace.

## How each network treats a mention

- Where you entered a handle, the mention is published as that handle ("Published as the handle").
- Where the network needs the profile looked up first (for example to tag a LinkedIn page), the mention shows "needs the profile looked up, or the mention is only text". Search for the profile to link it.
- Where a network is left empty, the name is published as plain text.

A profile found on one network only works on that network. If you need different wording for one network, give that account its own [version](/guide/publishing/post-versions) and search for the profile there.

<Note>
LinkedIn's search needs at least 3 letters and no digits, and 6 characters when the term contains a space or a full stop.
</Note>

## Edit or delete a mention

Open the Mention Manager, open a mention's **More actions** menu, and choose **Edit** or **Delete**. You can also click a mention chip in the text to edit it.

Deleting a mention asks you to confirm: posts that still use it publish the name as plain text.

## Troubleshooting

| Message | What it means |
| --- | --- |
| **Nobody found on {network}.** | The search returned no profile. Check the spelling, or keep the name as text. |
| **{network} does not let this account search for people.** | The connected account isn't allowed to search on that network. Type the handle instead. |
| **Reconnect this {provider} account to search it** | The connection has expired. Reconnect the account on the **Accounts** page. |
| **{network} asked us to slow down. Try again in a minute.** | The network is limiting searches. Wait and try again. |
| **Another mention already uses this profile.** | Each profile can belong to only one saved mention. Edit the existing one instead. |

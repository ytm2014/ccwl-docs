Templates let you start from a designed theme and then make it yours. Each template shows a sample page in that theme, so you can see the background, buttons and fonts before you use it. To open the gallery, click **Browse templates** on the **Pages** list, choose **From a template** when you create a page, or go to **Bio Links** → **More** → **Themes**.

The gallery has 13 themes: Antalya, Brand, Cream, Forest, Lake, London, Midnight, Mono, Noir, Paris, Sunset, Sydney and Tokyo. Each card shows the theme's name and a short description of its style.

Anyone in the workspace can browse the gallery. Using a template changes or creates a page, so it needs the **Admin** or **Member** role.

## Use a template

<Steps>
  <Step title="Pick a template">
    Hover over a card (on a touch screen the button is always shown) and click **Use template**.
  </Step>
  <Step title="Choose where it goes">
    In the **Apply "…"** dialog, either click **New page** to start a new page with this theme, or choose one of your existing bio pages to apply it to. With a long list, use **Search pages** to find it.
  </Step>
  <Step title="Fine-tune it">
    The page's editor opens with the new theme. Change the background, buttons, fonts and layout on the **Appearance** tab. See [Choose a look](/guide/bio-links/pages#choose-a-look).
  </Step>
</Steps>

A new page made this way gets a randomly generated address on your default domain and starts paused, like any new page. You can change its address on the editor's **Settings** tab.

Applying a template to an existing page sets its theme and clears the appearance changes made on that page. Your blocks stay as they are. The template is applied as soon as you pick the page; you don't need to save the editor afterwards.

<Note>
If the page still uses the look it was imported with from an earlier setup, you're asked **Switch to the new look?** first. Click **Switch and apply** to move it to the new look with this template.
</Note>

## Change the theme later

You can switch themes at any time from the theme tiles on the editor's **Appearance** tab. Switching theme there also clears your button, font and accent changes, and you're asked to confirm before it does.
